# Pacote de partida — equipe de especialistas

Este pacote separa o método de trabalho das seis skills do Meu Visto Fácil das regras particulares daquele produto. Foi preparado em 2026-09-29 para servir de entrada a um novo projeto.

## Conteúdo

- `skills/`: seis versões genéricas propostas, com metadados e instruções próprias.
- `originais/`: cópia fiel das seis skills e do AGENTS.md de origem, somente para consulta histórica. Não instalar essa pasta como instruções da equipe.
- `MAPA-DE-EXTRACAO.md`: origem, decisões de adaptação e regras que permanecem no produto.
- `EQUIPE.md`: papéis, limites e contrato de passagem de tarefas.
- `templates/CONTEXTO-DO-PROJETO.md`: formulário para integrar cada projeto atendido.
- `INICIAR-NOVO-PROJETO.md`: pedido pronto para iniciar a construção da equipe.

## Como levar

Copie esta pasta inteira para o novo projeto e comece pelo pedido em INICIAR-NOVO-PROJETO.md. Preserve as originais como referência, fora dos caminhos de descoberta de skills.

As versões genéricas são uma base revisada, ainda não validada em execução em vários projetos. Não foram instaladas globalmente nem substituíram as skills atuais. Este pacote não configura processos de agentes, modelos, permissões, memória persistente ou ferramentas de orquestração. A escolha e a validação desse mecanismo fazem parte do novo projeto.

Não é necessário copiar código, banco, credenciais ou documentação privada da aplicação. O contexto de cada projeto deve ser fornecido separadamente. Os caminhos e ferramentas reais devem ser descobertos no projeto atendido, não presumidos a partir deste pacote.
