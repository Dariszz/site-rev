# Pedido para iniciar o novo projeto

Copie o texto abaixo para o novo projeto junto deste pacote.

---

Quero construir uma equipe reutilizável de agentes especialistas para atender vários projetos de software.

Este pacote contém seis skills genéricas derivadas de um projeto existente, cópias das originais para rastreabilidade, um mapa de extração e uma proposta de papéis.

Leia README.md, MAPA-DE-EXTRACAO.md e EQUIPE.md. Consulte as skills genéricas conforme necessário; as originais servem apenas para comparação e não são instruções deste novo projeto.

O objetivo é separar:
1. Competências e limites estáveis dos especialistas.
2. Contexto e regras específicos de cada projeto atendido.
3. Mecanismo efetivo de criação, coordenação e verificação dos agentes.

Comece avaliando a base e as capacidades disponíveis no ambiente. Proponha uma estrutura simples e um plano verificável para configurar a equipe. Não presuma que arquivos SKILL.md já criam agentes independentes. Não instale as versões específicas do Meu Visto Fácil como regras globais.

Priorize os seis papéis existentes: coordenador, arquiteto, implementador, QA, revisor e segurança. Especialistas adicionais podem ser propostos quando houver necessidade concreta.

A solução deve permitir iniciar uma tarefa com o contexto de outro repositório, atribuir responsabilidades claras, impedir conflitos de edição, integrar resultados e apresentar evidências de testes. Respeite permissões e não misture dados de projetos diferentes.

Valide a solução com cenários de stacks diferentes, uma tarefa pequena sem delegação desnecessária, uma tarefa com trabalho paralelo autorizado, uma revisão sem edição e uma falha de teste que impeça uma falsa conclusão de sucesso.

Não imponha Next.js, Prisma, Supabase, pnpm ou regras de imigração a projetos que não os utilizem. Não crie uma aplicação web, banco, plataforma de memória ou painel administrativo sem necessidade demonstrada.

Entregue a configuração efetivamente suportada pelo ambiente, instruções de uso, resultados dos cenários executados e limitações. Diferencie configuração funcional de proposta ainda não implementada.
